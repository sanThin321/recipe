# 🍳 Recipe Sharing

A **Recipe Sharing Web Application** developed using **Go (Golang)** for the backend and **HTML** for the frontend. Users can create accounts, share their favorite recipes, and view recipes shared by other users.

---

## 🚀 Overview

The Recipe Sharing App allows users to:

1. **Register and log in** to their account
2. **Create and share recipes** with the community
3. **Browse and view recipes** shared by other users

This application provides a simple, interactive platform for recipe enthusiasts to share their culinary ideas.

---

## 🛠️ Tech Stack

### Backend

* **Go (Golang)**: Handles user authentication, recipe storage, and API endpoints
* Stores user and recipe data (could be in-memory, file-based, or database)

### Frontend

* **HTML**: Provides user interface for account creation, recipe submission, and viewing shared recipes
* Optional: Can be enhanced with CSS and JavaScript for better UX

---

## 🔑 Features

* **User Authentication**: Sign up and log in to create a personal account
* **Recipe Creation**: Add title, ingredients, and preparation steps
* **Recipe Sharing**: Share your recipes with the community
* **Recipe Viewing**: Browse recipes posted by other users

---

## 📌 Application Flow

1. User registers or logs in
2. User creates a new recipe
3. Recipe is saved on the backend
4. Other users can view shared recipes
